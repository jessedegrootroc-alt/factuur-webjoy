# Webjoy Facturen

Invulbare factuurtool in de Webjoy-huisstijl. Open `index.html` in je browser, vul klant en regels in, en klik op **Download als PDF** voor een A4-factuur op één pagina.

- Btw (21%, 9%, 0%), subtotaal, totaal en vervaldatum worden automatisch berekend.
- Je eigen bedrijfsgegevens worden in je browser onthouden.
- **Volgende factuur** verhoogt het factuurnummer en maakt klant en regels leeg.

Lettertypen: Google Sans Flex, JetBrains Mono en Caveat (via Google Fonts). PDF via html2canvas en jsPDF.
